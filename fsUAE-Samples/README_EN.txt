#FS-UAE Sample Configurations for AmigaED 4.0
================================================
This folder contains sample configurations for
FS-UAE that you can use in the Preferences window of
AmigaED.

A500-AmigaED.fs-uae provides an enhanced Amiga 500
with ECS and Workbench 1.3. The virtual hard disks
are mounted as writable directories on the host system.
A shared drive for data exchange
with AmigaED is also available.

A1200-AmigaED.fs-uae provides a heavily enhanced, Internet-ready 
Amiga 1200 with an AGA chipset and an RTG graphics card. The operating system
is mounted on an RDB-formatted virtual hard disk in .hdf format.
In addition, this configuration includes a shared drive for data exchange
with AmigaED.

Please note that you must customize these configuration files. This
applies in particular to file paths.
