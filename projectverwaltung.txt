ich möchte eine Projektverwaltung implementieren. Das Menu "File" soll nach dem Eintrag "New" um 2 Menüpunkte "New Project..." und "Load Project" erweitert werden. Die Projektverwaltung soll aus einem Tree View, sowie Buttons zum hinzufügen und entfernen von im tree view selektierten Einträgen bestehen. Die einträge sollen nach ihrem Typ (C/C++ Datei, Header Datei, Installer script) sortiert angezeigt werden. Das Tree view soll im Hauptfenster horizontal vor den TABs angezeigt werden und in seiner Größe horizontal verschieblich sein. Außerdem soll ein doppelklick auf einen Eintrag im Tree view die entsprechende Datei im Editor öffnen, falls sie nicht bereits geöffnet ist.
der Menüpunkt "New Project..." soll die folgenden Untermenü-einträge besitzen:
"Empty Amiga C Project", "Shell Project", "AmigaOS 1.3 Project", AmigaOS 3.x Project", ReAction Project", "MUI Project". Das Projekt, bzw. seine beschreibung soll unter einem frei wählbaren namen mit dem Suffix ".aep" gespeichert werden können. diese beschreibung soll über den Menüpunkt "Load Project" wieder geladen werden können, wobei alle zum projekt gehörenden Dateien im Editor je in einem eigenen TAB geöffnet werden. Im Tree View soll eine C/C++ Datei als "Hauptdatei" für die Compilierung bestimmt werden. Initial sollen mit einem neuen Projekt Makefiles für m68k-Amigaos-gcc und vbcc erstellt werden, die immer dann aktualisiert (automatisch) werden, wenn eine Datei zum Projekt hinzugefügt oder entfernt wurde. Makefiles sollen eine Option "clean" zum bereinigen des Projekts enthalten. Vor dem erstellen der Makefiles soll der Benutzer nach eventuellen zusätzlichen optionen für compiler und linker gefragt werden.

das Menu "Build" soll nach dem Eintrag "Compile..." einen Eintrag "Build Project" und einen Eintrag "Clean Project" erhalten. "Clean Project" soll veranlassen, dass in Abhängigkeit zum gerade ausgewählten Compiler das zum Projekt gehörige Makefile mit der Option "clean" aufgerufen wird. "Build project" soll veranlassen dass in Abhängigkeit zum gerade ausgewählten Compiler das zum Projekt gehörige Makefile mit der Option "all" aufgerufen wird.

Beim Speichern oder Speichern als... einer Datei soll, falls diese nicht bereits im Projekt enthalten ist, gefragt werden, ob sie zum Projekt hinzugefügt werden soll.
